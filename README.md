\# Personal Firewall



A beginner-friendly Windows firewall management project built with Python and Windows Defender Firewall.



\## About the Project



Personal Firewall is a Python application designed to check Windows Firewall status and manage a custom IP-blocking rule. It uses PowerShell commands to interact with Windows Defender Firewall.



This project was created to learn about network security, firewall rules, IP addresses, and Python automation.



\## Features



\- Check the status of Windows Firewall profiles.

\- Create a custom outbound IP-blocking rule.

\- Remove the project's test rule.

\- Validate IP addresses before creating a rule.

\- Handle common command errors.



\## Technologies Used



\- Python

\- PowerShell

\- Windows Defender Firewall

\- Git and GitHub



\## Requirements



\- Windows 10 or Windows 11

\- Python 3

\- PowerShell

\- Administrator permissions for firewall rule management



\## How to Run



1\. Clone or download this repository.

2\. Open Command Prompt as Administrator.

3\. Navigate to the project directory.

4\. Run:



&#x20;  ```bash

&#x20;  python firewall.py

&#x20;  ```



5\. Follow the menu prompts.



\## Safety Notice



This is a learning project, not a replacement for Windows Defender Firewall or a complete commercial security product.



The current test rule uses `192.0.2.1`, a documentation-only IP address. Review all firewall rules before using the application on a real network.
